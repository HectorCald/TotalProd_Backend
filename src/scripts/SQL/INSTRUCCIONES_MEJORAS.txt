INSTRUCCIONES PARA IMPLEMENTAR MEJORAS DE MOVIMIENTOS
═══════════════════════════════════════════════════════════════════════════════

PASO 1: INSTALAR DEPENDENCIAS
------------------------------
cd backend
npm install pdfkit

PASO 2: EJECUTAR FUNCIONES RPC EN SUPABASE
-------------------------------------------
1. Abre tu proyecto en Supabase (https://supabase.com)
2. Ve a SQL Editor
3. Copia y pega el contenido de: backend/src/scripts/SQL/rpc_functions.sql
4. Ejecuta el script (botón RUN)

PASO 3: VERIFICAR FUNCIONES
----------------------------
Ejecuta esto en el SQL Editor para verificar:

SELECT routine_name 
FROM information_schema.routines 
WHERE routine_schema = 'public' 
AND routine_name IN (
    'update_stocks_batch',
    'create_movimiento_atomico',
    'anular_movimiento_batch',
    'increment_cliente_total_orders',
    'decrement_cliente_total_orders'
);

Debes ver 5 funciones listadas.

PASO 4: REINICIAR SERVIDOR
---------------------------
cd backend
npm run dev
